# Trail of Bits says 1Password's AI patching benchmark is misleading

**Published:** Sep 15, 2026

> **Takeaway:** Before trusting or dismissing an AI-patching statistic, check sample selection, adversarial prompts, tool access and grader validity, and compare against human fix quality.

## TL;DR

Trail of Bits reanalyzed 1Password's FLAWED benchmark and found its 26% clean-fix headline pools hand-picked hard bugs, prompts that tell agents to apply the wrong fix, and trials where agents were barred from running code. Restricted to trials where agents could run code and got no bad instructions, 86% of patches blocked the supplied exploit. They also report human first-fix failure (12.5%) and maintainer acceptance of agent-written patches (67.7% merged) as comparison points, and release two agent skills.

## Lessons

- A pooled benchmark headline can hide the effect of deliberately adversarial prompts and tool restrictions. Report those trials separately. - _"In those trials, 2,634 of 3,067 patches generated by 1Password’s models (86%) blocked the supplied exploit."_
- Judge agent patch quality against a human baseline: developers also get first fixes wrong. - _"Even under those favorable conditions, 283 first fixes failed to fully resolve the reported issue: 12.5%, or one in eight."_
- A patch-validation check must fail on the vulnerable revision and pass on the patched one, or it proves nothing. - _"A test that passes on both revisions cannot demonstrate a fix."_
- Humans and agents can fall into the same trap: both freenginx fixes missed a cleanup-path crash. - _"Two authors, one human and one agent, working separately, made the same mistake on the same bug."_
