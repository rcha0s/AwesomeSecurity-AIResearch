# Weekly focus digest

The last 7 days up to 2026-11-22, in your focus areas: MCP security, Prompt injection, AI supply chain, AI-assisted security review, Guardrails, Red teaming, AI regulation for insurers.

## Stories

- [UK AISI found a universal jailbreak in pre-release OpenAI GPT-6.2 Astra](https://thehackernews.com/2026/11/threatsday-gpt-62-jailbreak-flaws.html) - A new model version can be easier to jailbreak than its predecessor, so re-run jailbreak testing on every release. _(Prompt injection)_
- [Google explains how Duplex phone-calling moved from narrow models to Gemini](https://research.google/blog/how-google-duplex-evolved-to-also-call-businesses-for-you-in-gemini/) - Guardrail-heavy scaffolding built for weaker models was dropped as models improved, so retest your harness when the model changes. _(Guardrails)_
- [Todoist MCP HTTP server lets websites edit Todoist data via DNS rebinding](https://github.com/advisories/GHSA-833v-v58w-294h) - Binding an MCP server to loopback is not authentication: HTTP-mode MCP servers need Host and Origin validation plus a per-run caller secret. _(MCP security)_
- [Google built an isolated 'Mirror Dimension' web to test Chrome agents](https://www.wired.com/story/google-built-a-giant-mirror-dimension-internet-to-test-its-chrome-ai-agents/) - Agent builders can test browsing agents against hidden prompt injection in a fully controlled web instead of the open internet. _(Prompt injection)_
- [PIPETTE paper trains LLM agents against prompt injection with broader attacks](https://arxiv.org/abs/2611.24362) - When hardening agents with red-team findings, measure the variety of attack strategies, not only the attack success rate. _(Prompt injection)_
- [CISA adds LiteLLM remote code execution flaw to its exploited list](https://nvd.nist.gov/vuln/detail/CVE-2026-40217) - If you run a LiteLLM gateway, treat it as exposed to code execution until you have patched or blocked the guardrail test routes, and check for signs of compromise. _(Guardrails)_
- [Criminals adopt ARTEX AI hacking tool to attack banks and governments](https://www.wired.com/story/artex-ai-hacking-tools/) - These tools add speed and lower the skill bar rather than add new techniques, so patching and credential hygiene still decide outcomes. _(Red teaming)_
- [UK AISI: undoing protein-model training-data filtering costs about $80](https://www.aisi.gov.uk/blog/pretraining-data-filtering-in-open-weight-biological-models) - Pretraining data filtering raises the cost of misuse but is not a durable safeguard for open-weight models on its own. _(Guardrails)_
- [AI Security Institute finds agents can rebuild simple biology AI tools](https://www.aisi.gov.uk/blog/can-ai-coding-agents-rebuild-biological-ai-tools-from-a-paper) - Do not treat withholding code or trimming a paper as a release safeguard for a dual-use model; gate the data and test with an agent rebuild eval. _(Red teaming)_
- [Pretxt raises $5M seed for runtime AI agent supervision that steers agents](https://www.securityweek.com/pretxt-emerges-stealth-with-5m-seed-and-an-ai-supervision-tool/) - Runtime agent supervision is becoming a product category; ask any vendor for evidence of detection and bypass rates, since this article offers none. _(Guardrails)_
- [Simon Willison and Prime Radiant release external sandboxes for coding agents](https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/) - Running agent-executed code in a separate sandbox, with an allow-list proxy and no secrets handed to the agent, limits the damage from a mistake or prompt injection. _(Prompt injection)_
- [OpenAI releases CSAM image classifier and ChatGPT warnings for child safety](https://openai.com/index/strengthening-online-child-safety) - Teams building on AI platforms can get a free image classifier and developer guidance for detecting child sexual abuse material (CSAM), including AI-generated images, but OpenAI's figures are its own… _(Guardrails)_
- [White House officials urge easing liability so AI firms report incidents](https://www.insurancejournal.com/news/national/2026/11/16/892718.htm) - US policy is leaning toward incentives over penalties for AI incident reporting, which could change how openly AI companies disclose security failures. _(Guardrails)_
- [StepSecurity reports attackers adopted open-source ARTEX AI pentest tool within three months](https://www.stepsecurity.io/blog/artex-ai-pentesting-tool-attackers-leaked-secrets) - Leaked secrets are the fastest way in for ARTEX agents, so find and rotate exposed credentials before they do. _(Red teaming)_
- [CodeRabbit partner post says AI agents make code flaws easier to exploit](https://www.theregister.com/security/2026/11/16/partner-content-has-ais-black-october-changed-the-way-you-secure-your-code/5309775) - Partner content that sells CodeRabbit Secure; its incident references are second-hand and its findings counts are the vendor's own. _(AI-assisted security review)_
